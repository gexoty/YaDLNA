## Что сохранено

- `releases/station-dlna-0.1.1-armhf`: 322 128 байт, SHA-256 `17bc84eaf317b8dedca9db763e8c629e8215a1914b510a61d6915f8e1b427fca`.
- `src/`, `build/`, `tests/`: исходники и проверки.
- `packaging/`: два init-скрипта, соответствующие рабочей интеграции.
- `scripts/install-on-station.sh`: установщик для новой Mini 2 с проверками root, модели, зависимостей, конфликтов и контрольных сумм. Завершается при ошибке, не перезагружает автоматически.
- `docs/INSTALL-ADB.md`: установка при уже имеющемся root ADB; SSH/Entware не требуются.
- `docs/UPDATE-ROLLBACK.md`: замена только своего бинарника и полный откат.
- `docs/BUILD.md`, `docs/ARCHITECTURE.md`, `docs/TROUBLESHOOTING.md`, `docs/TEST-REPORT.md`: сборка, устройство, диагностика и результаты.
- `dist/yadlna-0.1.1-mini2.tar` и `.tar.sha256`: готовый локальный установочный комплект с помощником, документацией и внутренним манифестом.

`local-deps/`, `dist/`, сборочные результаты, журналы и личные backups исключены из Git. Upstream bt-proxy не лицензирован нами как MIT: в проверенном upstream не обнаружен отдельный LICENSE. Поэтому его неизменённые файлы доступны в локальном комплекте, но не включены в отслеживаемый Git. Новый клон получает их через `python scripts/fetch-bt-proxy.py` с закреплённым commit и SHA-256, затем выполняет `python scripts/package.py`.

В репозиторий не переносились приватные сессии, URL с токенами, копии прошивки и музыкальные файлы. `.dockerignore` исключает локальные зависимости и личные резервные копии из Docker build context.
