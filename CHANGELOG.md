# Изменения

## 0.1.1 — 2026-10-27

- Исправлен HTTPS Navidrome: статическая libcurl и штатные OpenSSL/CA вместо отсутствующего GIO TLS backend.
- Сохранены проверка сертификатов/hostname и HTTP Range, запрещён HTTPS→HTTP downgrade.
- TRANSITIONING до реального PLAYING; числовые ошибки без полного auth-URL.
- Подтверждено слышимое воспроизведение на Mini 2.
- Подготовлены ADB-гайд, автозапуск, обновление, откат и локальная упаковка.
- Документировано ограничение голосового Previous: звук и очередь клиента могут разойтись. Исправление только в приёмнике не реализовано.

## 0.1.0

Первый C UPnP/MPRIS-приёмник и интеграция bt-proxy. Для установки использовать 0.1.1 с исправлением HTTPS.
