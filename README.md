# YaDLNA — лёгкий UPnP-приёмник для Яндекс Станции

Версия **0.1.1**, проверена на **Станции Мини 2**. Воспроизводит HTTP/HTTPS-потоки Navidrome через штатный GStreamer, принимает управление от Feishin (Windows, DLNA) и Symfonium (Android, UPnP). Голосовое управление Алисы связывается с плеером через отдельный bt-proxy и MPRIS.

Бинарник приёмника — **322 128 байт**. На проверенной станции RSS во время воспроизведения около **12,5 МиБ**, включая общие библиотеки; это не PSS всей интеграции. Внешний bt-proxy — около 1,13 МиБ на диске. Python, Node.js и Entware на станции не требуются.

**Известное ограничение:** голосовой переход назад воспроизводит историю приёмника, но интерфейс Feishin/Symfonium может остаться на текущем треке. Подтверждено владельцем в обоих приложениях; исправление не включено. Для синхронного перехода назад используйте приложение. [Подробности](docs/TROUBLESHOOTING.md).

## Быстрый старт

Для уже работающей станции повторная установка не нужна. Здесь сохранён комплект для новой установки и дальнейшей разработки.

1. Нужны ПК с ADB и Python 3, root-доступ через ADB к поддерживаемой станции.
2. В этом локальном комплекте уже есть `dist/yadlna-0.1.1-mini2.tar` и его SHA-256.
3. После нового клонирования: `python scripts/fetch-bt-proxy.py`, затем `python scripts/package.py`.
4. Следовать [установке с нуля](docs/INSTALL-ADB.md). Установщик запускается только вручную после проверки предпосылок. Он не перезагружает колонку автоматически.

## Состав

`src/` — C-код; `build/` — Docker-сборка и генерация описаний UPnP; `tests/` — тесты; `packaging/` — init-скрипты; `scripts/` — упаковка и установка; `releases/` — проверенный ARM-бинарник; `docs/` — руководства.

`local-deps/` и готовый `dist/` сохранены на этом ПК, но исключены из Git: они содержат неизменённый сторонний bt-proxy, у которого в проверенном upstream нет отдельной лицензии. После клонирования этот компонент самостоятельно скачивается по закреплённому commit с проверкой SHA-256. MIT проекта не распространяется на него. Подробнее — THIRD_PARTY.md.

В репозитории нет прошивки, конфигурации аккаунта, URL с токенами или музыкальных файлов. Используйте приёмник внутри доверенной локальной сети: UPnP не требует аутентификации. Поддержка других моделей и прошивок пока не подтверждена.
